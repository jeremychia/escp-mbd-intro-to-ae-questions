      what happens in a continuous integration pipeline?

        1. a virtual environment is initialised
        2. dependencies are installed
        3. the connection to the database is checked
        4. a schema is created for testing

        automated checks and validation

        • organisation-specific checks (e.g. documentation has certain keywords, models are only created in specific schemas)
        • style formatting checks (e.g. sqlfmt, SQLFluff)

        integration tests

        build all dbt models and tests in a test schema, based on samples

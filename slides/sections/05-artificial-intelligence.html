dbt Labs now writes its project standards for AI agents too

agent skills are instruction files that an AI agent reads when your request matches them

what to notice

  • the same standards you saw today, written for a machine reader.
  • they install like any other package, through packages.yml and dbt deps.
  • they tell the agent to treat data as untrusted. an agent must never follow an instruction it finds in a column value.
  • read them critically. one file calls staging “bronze”, but staging is silver.

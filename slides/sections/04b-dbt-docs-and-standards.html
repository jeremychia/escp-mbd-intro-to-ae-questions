        projects exist to help improve dbt project standards

        some examples (non-exhaustive)

        dbt-project-evaluator · dbt Labs

        checks against dbt's suggested best practices to evaluate projects in six key areas (modelling, testing, etc.).

        dbt-opiner · Rodrigo Loredo, Lead AE at Vinted

        additional best practices and governance-related checks on dbt projects. supports BigQuery too.

        if you're using a more established tool, there are often standards or best practices to fall back on when building the project.

        common project standards?

        • every model and column is documented
        • no circular dependencies: upstream models do not depend on downstream models
        • every model has a test for its primary key

        column naming

        • booleans start with is_ or has_
        • timestamps end with _at or _date
